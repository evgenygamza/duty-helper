# Чек-листы дежурного

## Приём смены / начало дня

- [ ] Разобрать алерты, упавшие ночью/в выходные/праздники (обе ветки)
- [ ] `#factset-disasters-prod` и `-stable` — есть ли открытые (не auto-recovered)
- [ ] `Snapshot Datacheck failed` — не висит ли (требует ручного закрытия)
- [ ] Обход призывов `@qa-factset-dutyman` за период отсутствия (см. slack-triage)
- [ ] Дашборд FFD-318 — новые ответы по тикетам FactSet
- [ ] Открытые кейсы `in_progress` из `cases/journal.jsonl` — есть ли апдейты
- [ ] Принять контекст у сдающего дежурного: открытые задачи, текущие проблемы

## В течение дня

- [ ] Реакция на новый призыв **≤ 1 час** (прочитать, оценить, отписать)
- [ ] Взятый алерт: :eyes: → разбор → :acknowledged: + артефакт
- [ ] Дежурство приоритетнее текущих задач (кроме своей срочной приоритетной)
- [ ] Каждый разобранный кейс — в хронику (journal.jsonl)

## Передача смены / конец дня

- [ ] Все новые кейсы записаны в journal.jsonl с полями service/category/status
- [ ] `in_progress` кейсы — есть краткое «что дальше» для следующего дежурного
- [ ] Дашборд FFD-318 актуален (статусы, ссылки на треды/тикеты)
- [ ] Нет незакрытых `Snapshot Datacheck failed`
- [ ] Передать контекст сменщику: что в работе, что ждёт поставщика

## Когда звать на помощь

- 🔴 Disaster и за ~5 минут непонятно, что делать → `@factset-dev`,
  владельцы сервиса (Ops), `@devops-dutyman`
- Вопрос по данным вне нашей зоны → переадресовать профильной команде
- Нет прав (напр. мердж prod enum novы) → `#team-nova`
