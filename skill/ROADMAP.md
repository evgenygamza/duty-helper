## Решения

- канал приватный, состав по причастности: помогаем дежурным, не публикуем их работу
- карточка удаляется при заведении инцидента, но только после `Slack thread link`
- карточки-не-инциденты остаются — единственный учёт обращений без проблемы
- причина закрытия свободным текстом, статус реакциями
- дежурный берётся из задачи «Дежурство» в активном спринте FFD
- «никто не ответил» считается по составу `@factset-team`, порог 30 минут
- переписка с ФС живёт в инцидентах, доска 318 — наследие
- в канале и тредах пишет человек; помощник готовит текст и отправляет по «да»
