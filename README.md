# Помощник дежурного FactSet

Бот в Slack, который ведёт очередь обращений дежурного QA команды FactSet.

План и состояние — в `ROADMAP.md`.

## Что он должен делать

1. собирать упоминания по пространству
2. читать тред целиком
3. превращать обращение в элемент списка, саммари пишет ИИ
4. реагировать на нажатия в списке
5. писать комментарии к элементу

Правила дежурства, пороги и определение просадок живут в скилле
`~/.claude/skills/factset-duty`, рядом с остальными скиллами. В этом
репозитории их нет: бот ими пользуется, но не хранит.

## Архитектура

```
Slack
   ↓ поиск user-токеном раз в минуту          ↓ события по вебсокету
упоминания @qa-factset-dutyman            реакции и нажатия в #factset-duty
   ↓ прочитать тред → ИИ пишет саммари         ↓
slackLists.items.create                   комментарий, инцидент в ITSM, закрытие
```

### Почему сбор идёт поиском, а не событиями

Тегнуть могут в любом канале, списка «нужных» не существует, а события приходят
боту только оттуда, где он состоит. Вступать во все публичные каналы подряд
нереально: это тысячи записей «duty-helper joined» и отдельный разговор
с админами.

Поэтому:

- **поиск user-токеном** — основной механизм. Видит всё, где состоит человек,
  без вступлений. Реальное время достигается частотой: `search.messages`
  с `after=<последняя точка>` раз в минуту даёт задержку меньше минуты
  при регламенте в час
- **события** — только для действий в трекере: реакции и изменения элементов
  прилетают из `#factset-duty`, где бот и так сидит. Socket Mode нужен
  для этого, а не для сбора

User-токен действует от имени установившего приложение: бот увидит то же, что
видит человек, и действия пойдут от его лица.

Важная деталь запроса: хэндл группы пишется с `@`. `@qa-factset-dutyman`
находит настоящие теги `<!subteam^ID>`, без `@` поиск вернёт только текстовые
вхождения. Проверено 26.08.2026 в песочнице.

## Раскладка

```
README.md              это ТЗ и архитектура
ROADMAP.md             план, открытые вопросы, что проверено
DEPLOY.md              что делать иначе при переезде на прод
TESTS.md               что проверено и как, пополняется по ходу
bot/                   Slack-проект: код, pyproject.toml, .slack/
  manifest.json        права и подписки приложения, читает Slack CLI
temp/                  нужное только для разработки
  sandbox_check.py     проверка возможностей приложения
```

Токены песочницы и ключ модели — в `~/.config/duty-helper/sandbox.env`,
права 600, в репозиторий не попадают.
