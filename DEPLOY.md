# Переезд на прод

Черновик. Пополняется по мере того, как что-то выясняется в песочнице.
Пока бот живёт процессом на маке Гамзы, а всё окружение — в песочном
воркспейсе. Здесь копится то, что придётся сделать иначе.

Состояние на 01.09.2026: **не готово к переезду**, см. «Чего ещё не хватает».

## Что переносим

Один процесс на Socket Mode. Публичный адрес не нужен, входящих соединений
нет — бот сам открывает вебсокет к Slack. Значит ingress не нужен, нужен
только под, который не падает.

## Приложение Slack

Сейчас песочное приложение `A0BSPKGE32Q` в воркспейсе `T0BSDLTDKBM`.
На проде заводится отдельное приложение в рабочем воркспейсе.

1. набор прав собрать **по факту использования**, а не по догадке.
   Сейчас в манифесте 49 прав бота с запасом — на проде столько не нужно.
   Прежние обоснования по каждому scope: `git show deb4881:bot/SLACK-APP.md`
2. установка в рабочий воркспейс требует аппрува админа. Сколько это
   занимает — неизвестно, заложить время
3. `manifest.source: local` оставить: правка прав = правка `bot/manifest.json`
   плюс `slack install`. Веб-интерфейс не нужен
4. Socket Mode включён, подписки: `message.channels`, `message.groups`,
   `app_mention`. Подписка на `app_mention` не пройдёт валидацию без scope
   `app_mentions:read`

## Секреты

Всё, что сейчас лежит в `~/.config/duty-helper/sandbox.env`, на проде
приходит из секрета. Имена переменных в проде другие, но код к этому готов:
`config.py` принимает и `SLACK_BOT_TOKEN`, и `SLACK_SANDBOX_TOKEN`.

| переменная | что это | откуда на проде |
|---|---|---|
| `SLACK_BOT_TOKEN` | `xoxb`, бот | секрет |
| `SLACK_APP_TOKEN` | `xapp`, Socket Mode | секрет |
| `DUTY_GROUP_ID` | id группы призывов | конфиг |
| `DUTY_FEED_CHANNEL` | канал ленты | конфиг |
| `DUTY_LIST_ID` | доска | конфиг |
| ключ модели | Gemini или Anthropic | секрет |

User-токен (`xoxp`) понадобится на Э5 для поиска по пространству — см.
«Что нужно получить от людей».

## Модель

В песочнице Gemini на бесплатном тире — у организации Anthropic нет кредитов.
На проде вернуться на Claude: правка одного файла `bot/duty_bot/summarize.py`,
промпт и склейка треда не меняются. Заодно посмотреть, ложится ли сюда kagent.

Логин через `ant auth login` на проде не годится: браузера в кубере нет,
нужен ключ в секрете.

## Доска

Сейчас доску создал бот, а права раздавали руками через
`slackLists.access.set`. На проде разумнее, чтобы доску завёл человек:
тогда владелец сразу правильный.

Схема задаётся **только при создании** — `slackLists.update` умеет менять
имя, описание и `todo_mode`, но не колонки. Значит схему надо согласовать
до заведения прод-доски, иначе пересоздавать.

Порядок: создать со своей схемой → включить `todo_mode` → выдать каналу
`write` → прибить закладкой через `bookmarks.add`.

Колонки: обращение (primary), статус, проблема, разбор, данные, кто просит,
канал, тред, инцидент, заведено.

**Статусы завести сразу в правильном порядке** — переставить их потом нельзя,
API схему не меняет, а в интерфейсе двигаются только колонки вьюхи:

```
Новое → В разборе → Ждём FactSet → Ждём автора → Закрыто
```

В песочнице порядок другой (`Ждём автора` перед `Ждём FactSet`) — это
наследие первой сборки, на проде так делать не надо.

Вьюху по умолчанию (раскладка Board, группировка по статусу, закрытые
отфильтрованы) API не умеет — сохраняется руками кнопкой `Save as New View`.

## Что нужно получить от людей

Это не пишется кодом и не делается за вечер. Начинать заранее.

- **аппрув админа рабочего воркспейса** на установку приложения. Сколько
  занимает — неизвестно
- **чей user-токен.** Поиск по пространству работает только от имени
  человека и видит ровно то, что видит он. Значит надо решить, чей это
  токен, что будет, когда человек уйдёт из команды или уйдёт в отпуск,
  и устраивает ли команду, что действия идут от его лица
- **кто заводит и держит доску.** Владелец должен быть человеком, а не ботом
- **согласие команды на канал.** Куда ставим ленту и доску, кто в нём состоит
- **оплата модели.** Разработку Гамза оплачивает сам, прод — нет. Значит
  нужен ключ на организации компании и понятный владелец расхода.
  Порядок цифр: вызов на реальном треде ≈ 0.012$ на Opus 5, то есть
  десяток обращений в день ≈ 4$ в месяц
- **кто дежурный сейчас.** Сегодня имя захардкожено в скилле. Нужен источник,
  который меняется без правки кода
